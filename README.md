# УралПромГрупп — Лендинг компании по изготовлению мебели на заказ в Екатеринбурге

Премиальный конверсионный одностраничный сайт (Landing Page) для компании **«УралПромГрупп»** (г. Екатеринбург).

## 📌 Особенности проекта
- **Автономный Single-File**: HTML5 + CSS3 + Vanilla JavaScript в одном файле `index.html`.
- **Строгая фактология**: Исключены выдуманные отзывы, фальшивые цены и фиктивные награды.
- **Две темы оформления**: Светлая архитектурно-премиальная тема по умолчанию с возможностью моментального переключения на тёмную тему (с сохранением в `localStorage`).
- **Интерактивный онлайн-консультант**: Встроенный виджет чата с умным помощником и быстрым переносом диалога в WhatsApp.
- **Полная мобильная адаптация**: Мобильное гамбургер-меню, плавающая панель быстрой связи (`Позвонить` / `WhatsApp`), 100% отсутствие горизонтального скролла.
- **Интерактивные элементы**: Квиз-калькулятор расчета проекта, векторный чертежник схем мебели на SVG, FAQ-аккордеон.

## 🚀 Деплой на GitHub Pages
1. Перейдите в **Settings** > **Pages** вашего репозитория `uralpromgroup-landing`.
2. В блоке **Build and deployment** выберите ветку `main` и каталог `/ (root)`.
3. Нажмите **Save**. Сайт будет автоматически доступен по адресу: `https://neirostuff.github.io/uralpromgroup-landing/`.
